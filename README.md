# Simple Notepad — Flutter / Android

A small Material 3 notepad app with:
- Create and edit notes
- Delete notes with a confirmation prompt
- Search note titles and content
- Local persistence using `shared_preferences` (notes remain after closing the app)
- A responsive Android-friendly interface

## Requirements

- Flutter SDK (stable channel)
- Android Studio with Android SDK and platform tools
- An Android phone with USB debugging enabled
- Vysor (optional, for mirroring and interacting with the phone from your computer)

## Create the Android project

This bundle includes the Flutter app source and dependency configuration. Generate the standard Android runner files with Flutter:

```bash
flutter create --platforms=android simple_notepad
```

Then copy `lib/main.dart` and `pubspec.yaml` from this bundle into the generated `simple_notepad` folder, replacing the existing files.

Open a terminal in that folder and run:

```bash
flutter pub get
flutter doctor
```

Resolve any Android toolchain issues reported by `flutter doctor`.

## Run on a connected Android phone

1. On the phone, enable **Developer options** and **USB debugging**.
2. Connect the phone to the computer using a USB data cable and accept the debugging authorization prompt on the phone.
3. Check that Flutter can see the device:

   ```bash
   flutter devices
   ```

4. Start the app:

   ```bash
   flutter run
   ```

If more than one device is listed, choose the phone with `flutter run -d DEVICE_ID`.

## Build an installable APK

From the project folder:

```bash
flutter build apk --release
```

The APK will normally be created at:

`build/app/outputs/flutter-apk/app-release.apk`

Install it over USB with:

```bash
flutter install
```

Or copy the APK to the phone and open it to install. You may need to allow installation from that source in Android settings.

## Use Vysor

Vysor mirrors and controls your Android phone; it is not the app compiler.

1. Install and launch Vysor on the computer.
2. Connect the phone by USB with USB debugging enabled.
3. Select the phone in Vysor and start mirroring.
4. Run `flutter run` from the project terminal, or install the APK built above. The app should appear on the phone and be visible in Vysor.

## Notes

- Notes are stored locally on the device using Android app preferences. They are not synced to an online account.
- Uninstalling the app or clearing its app data can remove saved notes.
- This project uses Flutter's standard Android project scaffold generated by `flutter create`.
